= Native host output

This directory is filled by `pwsh tools/build-host.ps1`.

It contains the DNNE native shim (`AvaloniaD.HostNE.dll` on Windows,
`libAvaloniaD.HostNE.so` / `.dylib` elsewhere) plus the managed Avalonia /
ShadUI assemblies it loads. Do not commit those binaries. Subfolders are
named by RID (`win-x64`, `win-arm64`, `linux-x64`, `linux-arm64`,
`osx-arm64`).
