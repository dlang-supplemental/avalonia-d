== 2026-08-17 — Multi-arch host CI

* GitHub Actions builds the DNNE host for `win-x64`, `win-arm64`, `linux-x64`, `linux-arm64`, and `osx-arm64`
* On `win-arm64`, CI skips LDC / `dub test` (no native windows-arm64 LDC package yet) and still publishes the host zip
* D loader selects `native/<rid>/` from OS + AArch64 vs x64

== 2026-08-17 — v0.1.0 (`0.1.0+avalonia.12`)

* Initial D bindings for Avalonia via a DNNE C ABI host
* ShadUI theme plus Window, Stack, Card, Button, Text, TextBox, CheckBox
* `tools/build-host.ps1` to publish the .NET host into `native/<rid>/`
